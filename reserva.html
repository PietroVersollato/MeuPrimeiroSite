Fundamentos do Desenvolvimento Web

Anotações e estruturas básicas de HTML, CSS e JavaScript utilizadas no aprendizado web.

O que é HTML?

HTML (HyperText Markup Language) é a linguagem de marcação padrão para a estruturação de páginas da Web.

  • HTML significa Linguagem de Marcação de Hipertexto.
  • Descreve a estrutura semântica dos elementos no navegador.
  • Consiste em uma série de elementos que rotulam o conteúdo (títulos, parágrafos, imagens, seções).

O que é CSS?

CSS (Cascading Style Sheets) é a linguagem utilizada para estilizar e definir a aparência visual de documentos HTML.

  • Controla cores, fontes, layouts, espaçamentos e responsividade em múltiplos dispositivos.
  • Permite criar temas avançados, animações e efeitos modernos de design.

O que é JavaScript?

JavaScript é uma linguagem de programação dinâmica de alto nível executada nos navegadores para criar interatividade e lógica.

  • Manipula dinamicamente o DOM (Document Object Model).
  • Cria filtros de conteúdo, animações, quizzes e requisições assíncronas.
